# Jarvis

An offline AI voice assistant built in Python.

## Features

- Voice commands
- Speech-to-text using Whisper
- Text-to-speech using Piper
- Application launching
- Web search
- System controls
- Local AI model integration
- GUI interface

## Installation

```bash
git clone https://github.com/Abbas-Barada/Jarvis.git
cd Jarvis
pip install -r requirements.txt
```

## Usage

```bash
python jarvis_main.py
```
